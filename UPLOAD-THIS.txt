WHAT TO DO WITH THIS ZIP (GitHub Pages) — UPDATE v3 (IMPORTANT)
===============================================================
What changed since the last update:
  - The fault timeline NO LONGER appears inside the app (it was clogging the
    screen). It is now an ADMIN-ONLY archive in admin.html.
  - When a car OR the fire alarm system is fixed, that point is archived in
    the timeline automatically (with the date it was fixed).
  - The admin panel timeline now has: a DELETE button on every archived
    (fixed) point, and an EXPORT button that downloads the whole timeline as
    a CSV file (opens in Excel).
  - (Previous fixes still included: every session pushes, and changes are
    ordered by Firestore server time, so wrong phone clocks no longer matter.)

REPLACE these two files in your repo (they already exist there):

                            phone downloads the new sync.js automatically)

GitHub Pages steps:
  1. Go to your repo on github.com -> "Add file" -> "Upload files".
  2. Drag ALL files from this zip into the upload box (root of the repo).
     Existing index.html and sw.js will be overwritten - that is intended.
  3. Commit.
  4. Repo -> Settings -> Pages -> Source: "Deploy from a branch" ->
     Branch: main -> Folder: / (root) -> Save.
  5. Wait ~1 minute, open the site URL.
  6. Phones pick up the new sync.js by themselves the next time they open the
     app (the offline-cache name changed). If one still misbehaves: open the
     app and press Ctrl+Shift+R once.

BEFORE or right after uploading (Firebase console, project "mag-toran"):
  1. Enable Firestore (if not yet): console.firebase.google.com/project/mag-toran/firestore
     -> Create database -> location me-west1 (Tel Aviv) -> production mode.
  2. UPDATE the security rules: paste the rules from SETUP.md (step 3) into
     Firestore -> Rules again — they now also cover the "faultTimeline"
     collection (without this the timeline will not sync).
  3. Get the VAPID key: console -> Cloud Messaging -> Web Push certificates
     -> Generate key pair -> paste into firebase-config.js (replace
     REPLACE-ME-WITH-YOUR-VAPID-KEY). Only needed for push notifications.
