WHAT TO DO WITH THIS ZIP (GitHub Pages) — UPDATE v6
====================================================
What changed since the last update:
  - THE ROSTER-PHOTO OCR (scan) IS MUCH BETTER: it now runs 3 recognition
    passes (classic, downscaled to the optimal text size, and a watermark-
    removing binarization) and merges the results. On a real phone photo of
    the roster this went from about 2 of 7 names recognized to 7 of 7.
    Tip: you can also add your team's names under "ניהול שמות לזיהוי" in the
    scan tab — the app then uses them to fix OCR mistakes.
  - Everything from the previous updates stays: the editable two-section
    timeline archive in the admin panel (see-more after 5, durations, edit,
    delete, export), every-session sync, server-time ordering, and phones
    updating themselves automatically.

REPLACE these two files in your repo (they already exist there):
  - index.html                (CHANGED — the improved OCR engine pipeline)
  - sw.js                     (CHANGED — new offline-cache name, so every
                              phone downloads the new index.html automatically)

ADD these six files (new or updated):
  - sync.js                   (updated - the sync engine)
  - admin.html                (updated - editable two-section timeline archive)
  - firebase-config.js        (your real config - already filled in)
  - firebase-config.example.js
  - SETUP.md                  (updated - read this, it is your checklist)
  - UPLOAD-THIS.txt           (this file)

DO NOT touch: manifest.json and the icon-*.png files (unchanged).

GitHub Pages steps:
  1. Go to your repo on github.com -> "Add file" -> "Upload files".
  2. Drag ALL files from this zip into the upload box (root of the repo).
     Existing index.html and sw.js will be overwritten - that is intended.
  3. Commit.
  4. Repo -> Settings -> Pages -> Source: "Deploy from a branch" ->
     Branch: main -> Folder: / (root) -> Save.
  5. Wait ~1 minute, open the site URL.
  6. Phones pick up the new files by themselves the next time they open the
     app (the offline-cache name changed). If one still misbehaves: open the
     app and press Ctrl+Shift+R once.

Firebase console (project "mag-toran") — only if not done yet:
  1. Enable Firestore: console.firebase.google.com/project/mag-toran/firestore
     -> Create database -> location me-west1 (Tel Aviv) -> production mode.
  2. Paste the security rules from SETUP.md (step 3) into Firestore -> Rules
     (they cover the "faultTimeline" collection that feeds the admin archive).
  3. VAPID key (only for push notifications): console -> Cloud Messaging ->
     Web Push certificates -> Generate key pair -> paste into
     firebase-config.js (replace REPLACE-ME-WITH-YOUR-VAPID-KEY).

THEN TEST THE SCAN: open the app -> scan tab -> upload a photo of the duty
roster -> the names should fill in automatically (check & fix, then apply).
Send me 2-3 more photos (different phones / angles / lighting) and I will
keep tuning the recognition.
